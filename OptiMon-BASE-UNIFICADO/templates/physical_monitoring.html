Descargar Script
Instrucciones:
  1. Descargar el script para tu sistema operativo
  2. Ejecutar con permisos de administrador en cada servidor
  3. Node Exporter se instalará automáticamente en puerto 9100
  4. Usar Discovery para detectar automáticamente los servidores
Comando Rápido:
# Linux/macOS:
curl -O http://localhost:5000/download/scripts/install_linux.sh && bash install_linux.sh

# Windows (PowerShell como Admin):
Invoke-WebRequest http://localhost:5000/download/scripts/install_windows.ps1 -OutFile install.ps1; .\install.ps1
